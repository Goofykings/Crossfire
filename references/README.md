# References

Design references only. Nothing here is loaded by the game or included in the build.

- `map-layout/maze-layout-overhead.jpg`: the primary layout reference (overhead maze blockout), extracted from the
  saved conversation page in `references_images/` (git-ignored).
- `map-layout/industrial-city-reference-sheet.png`: the reference sheet for the two new maps (top-down layouts, aerial
  views and building, prop, alley and interior references), saved from `references_images/9a74ed9e-….png`.
- `industrial-complex/layout.png`, `modern-city/layout.png`: the top-down layout panels cropped from that sheet. The
  current layouts in `tools/layout_industrial.py` and `tools/layout_city.py` were designed from the written brief and do
  not trace these plans (see docs/LEVEL_DESIGN.md).
- `european-town/town-ref-*.jpg`: photographs and renders setting the architectural style, materials and mood.
- `european-town/game-ref-*.jpg`: in-game screenshots of comparable maps (Mediterranean town lanes and arches).

before publishing it.
